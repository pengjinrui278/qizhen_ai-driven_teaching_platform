# 文档地图

> 文件太多不知道看哪个？**按下面的顺序读前三个就够了。**

## 阅读顺序

1. `项目概况总览.md` —— 项目在做什么、到哪了、下一步（5 分钟看懂）
2. `MathMirror_产品角色与开发参照_v0.2.md` —— 产品基准，所有开发以此为准
3. `development-roadmap.md` —— 阶段 0–6 怎么走
