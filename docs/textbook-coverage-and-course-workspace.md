# 数分教材完整覆盖与课程资源工作台

更新：2026-09-08；用户本轮授权教材处理 API 预算上限100元人民币。
适用基线：陈纪修《数学分析》第三版上下册，不混入第二版习题答案。
原书只作用户授权的本地处理；用户持有电子书不自动等于可向公网分发，正式分享须另行确认使用范围。

## 完整覆盖的验收定义

1. 每一PDF页均有状态：封面/目录/正文/空白/识别失败；总数必须对齐原文件，失败页不得算完成。
2. 每个正文页建立原书页码与PDF页码映射；章节、小节、标题来自书内目录与正文的交叉核验。
3. 定义、定理、阐释、证明分别存储：原书内容不与助手解释混在同一字段。
4. 例题及课后习题按原编号建条目，保留子题号、图形、适用条件和跨页范围；粗体只是一项版面证据。
5. 遇到缺号、重号、跨页未衔接、公式含糊或图形丢失，相关条目必须退出可用题库。
6. 题目到知识点链接区分原书明确关联与解题分析推断；推断标记及依据必须保留。
7. 单元包含教材/版次/册别/章节/小节/原编号/印刷页/PDF页/来源哈希，不能回答时由LLM猜页码。
8. 全页识别、结构校验、公式复核、完整性核对分别统计，不用一个“100%”掩盖未验收项。
9. 抽查问答不能替代全书质量验收。已识别但未核对内容仅进候选库，不进入准确检索索引。
10. 若用户指定定理/题号未能唯一定位，先澄清版本和册别；证据不足则明确说未找到，不编造原文。

## 分工（设计，未冒称已经全部实现）

| 助手 | 唯一核心职责 | 输入与输出边界 |
| --- | --- | --- |
| 答疑 | 引导学习、解释与证明讨论 | 调用寻知结果；区分原书表述与解释，不虚构出处 |
| 寻知 | 定位教材知识点和原题 | 只返回可追溯来源；同名定理按版本区分 |
| 编题 | 组织原书例题/习题、同类题检索 | 不把新编题冒充教材原题；新编内容独立标识和验收 |
| 拾记 | 整理个人感悟、复习笔记 | 草稿和证据链接由本人确认，可编辑撤回 |
| 学迹 | 生成学习时间线及证据图表 | 不把时长、提问次数或自报完成换算成掌握度 |

这些是有工具和权限边界的逻辑角色，不必各自微调一个模型。
只有确实执行相应任务时，界面才显示“寻知 · 正在定位教材”等轻量状态。
不展示私有推理过程，不模拟后台不存在的多人协作。

## 课程工作台页面

- 对话：保留单一聊天中心，资料来源卡可跳到书中对应页/原题。
- 教材：按书名、版次和册别组织；目录导航、全文检索、来源页阅读。未授权公网分发的教材只在受控范围使用。
- 例题与习题：按教材→章节→小节→例题/习题展开；可筛知识点。题卡始终显示原编号与出处。
- 试卷：等待用户提供；显示学校/课程/年份/考试类型/使用范围，不造样卷冒充历年试卷。
- 我的笔记：我写的、助手草稿、我确认的；每条可查看来源消息、教材页或正式作业证据。
- 教师信息：学生与课程教师的显式匹配，教师控制作业形式、小测、教学计划、点名等字段的可见性；不推断或抓取个人信息。
- 学习反馈：承接学迹的时间线与证据图表，不在课程页再复制一套不同口径的统计。

整体视觉留给用户后续Zion设计，以上是信息架构，不代表页面已经上线。
AI教学模块仍排除在本轮改动之外。

## 易错点与隐私

- 学生“问过某知识点”不等于做错。
- 一次对话中的重复追问不算多次独立错误；同一证据去重。
- 明确错因至少需可复核的数学推导/正式教师反馈支撑；无法验证只生成待核对笔记草稿。
- “频繁”统计需显示时间窗、独立任务数量、证据来源和相反证据；阈值可配置，不能硬写成能力标签。
- 私人聊天、笔记和时间线默认本人可见；不因关联课程就向教师公开。
- 自动整理需有可关闭开关，支持查看依据、修正、删除及冻结。
- 学习时长只统计有依据的前台活动区间，空闲页面不当作有效学习时间。
