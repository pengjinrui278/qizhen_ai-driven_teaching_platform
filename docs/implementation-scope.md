# 内测版实施约定（2026-09-07确认）

- 在独立副本实施，截止目标2026-09-27；不自动推送或上线。
- AI教学原有页面、内容不改造。新数理学习工作台与教师Sandbox独立推进。
- 开发成员注册测试账号；教师/TA角色通过开发团队邀请码授予，未来替换身份提供方。
- 私人题目直接答疑；贡献共享题库需另外同意、课程归属审查与发布审核。
- 不把课程相关性等同于数学正确性，也不自动把对话转成参数训练数据。
- 学生记忆采用观察、支持/相反证据、可纠正假设；不显示能力百分比。
- 教师只见聚合、正式提交作品；学生私聊/草稿默认不可见。
- Sandbox测试期默认3小时，正式期默认7天，创建时教师确认，可配置。
- 到期冻结报告并清理临时关联/作业作品；个人证据独立保存；提供个人导出/删除。
- 数分首个主题选数列极限、量词与定理条件，承接现有课程包。
- ds-v4-pro模型标识可配置；密钥不入库。真实模型与人工教学效果单独验收。

实施顺序：可信基础→学生闭环→教师作品与生命周期→课程审核/Eval→界面与集成测试。
