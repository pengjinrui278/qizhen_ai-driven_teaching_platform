# 数据与版权门禁

每个 Source 或 Dataset Record 必须分别声明：

- `allowed_for_runtime`
- `allowed_for_rag`
- `allowed_for_eval`
- `allowed_for_training`
- `retention_policy`
- `license_note`

“学生上传用于当前答疑”不自动等于“允许训练”；“购买教材”不自动等于“允许批量复制或模型训练”。训练集导出必须按字段自动过滤，并保留导出清单和审核人。

当前数分试行数据只使用出版社公开书目信息、公开目录层级和自编数学样例。教材正文、例题和习题全文需在获得明确授权或由团队合法录入后进入受控 CoursePack。
