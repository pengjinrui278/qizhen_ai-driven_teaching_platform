# 参赛指南：摘要与行动清单

## 与我们直接相关的要求

| 维度 | 要求 |
|---|---|
| 作品形态 | 选择生成式 AI 通用大模型及技术平台作为基座，聚焦某一教学场景，**自选自建数据语料库**，训练打造教育教学模型或智能体 |
| 赛道 | 二选一：①教育教学垂直领域大模型；②教育教学智能体（基于国内通用大模型、平台工具开发） |
| 功能要求 | 聚焦真实教学场景，具备提升教学效率、个性化学习、学习评价等核心功能 |
| 团队 | ≤4 人：教师负责人 1 + 学生负责人 1 + 其他成员 ≤2；每人只能参加一个团队 |
| 赋能环节 | 课程设计、课堂教学、学业评价、个性化辅导等 |

> 赛道选择提示：本项目当前形态（基于通用大模型基座 + 课程语料库 + 教学智能体链路）更贴近**“教育教学智能体”**赛道。最终以团队确认为准，确认后在进度日志中记录。

## 评审维度（对照自查）

1. **创新性**
2. **教学应用价值**
3. **技术实施质量**
4. **用户体验与可推广性**
5. 特别关注：真实教学场景中的**落地效果**、**“师-生-机”协同**的体现程度

→ 开发路线（`docs/development-roadmap.md`）中的三端界面（学生 / 课程建设 / 教师·TA）正好对应“师-生-机”协同的展示。
