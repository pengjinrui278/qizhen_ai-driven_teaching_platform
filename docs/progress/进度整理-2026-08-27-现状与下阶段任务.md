## 一、现状总览

### 1. 产品设计（已定稿）

以 `docs/MathMirror_产品角色与开发参照_v0.2.md` 为产品基准（"产品宪法"），核心设计：

- **三大对象**：Student Mirror（认识学生、最小上下文、三层记忆）、Course Mirror（课程知识 + 解法结构 + Hint Ladder + Harness + Eval）、Assignment Workspace（班级作业周期的临时上下文，截止后生成报告并清理）；
- **核心方法论**：假设—证据—更新（不分类、不打分、不贴标签）；诊断是学习的副产品；
- **双通道证据**：求助轨迹 = 深度过程证据（覆盖少数但深入），作业 + TA 批改 = 全覆盖作品证据，小测 = 独立能力证据；教师报告必须标注样本覆盖，禁止以部分数据外推全班；
- **"1+4"课程策略**：数学分析（陈纪修等《数学分析》第 3 版，高教社）旗舰深做，高等代数与解析几何、大学物理、点集拓扑、常微分方程四门做到真实可用；**示例课程严格限定这 5 门**；
- **数据权利**：教材的上传、检索（RAG）、评测、训练是四种不同授权范围；目前教授授权 = 平台解析 + 知识库/RAG 使用，**训练与独立评测权限保持关闭**。
