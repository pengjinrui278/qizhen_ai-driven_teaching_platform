## 2026-08-28 学生端交互页面上线，智能体接入 DeepSeek 真实模型

**更新内容**

- **agent 首次在浏览器可见可演示**：新增学生端页面 `/student`（首页加入口）——左侧第一章题库（10 道自编题，标注题型与提示级数），右侧对话区支持"我卡住了给提示 → 再提示一级（阶梯用完自动置灰）→ 看完整解答思路 → 知识点答疑"；每条回答附课程引用、Harness 质检状态与学习证据，回答用 Markdown + KaTeX 渲染（标题/列表/行内与块级公式）；

- **新增接口**：`GET /api/v1/problems`（学生端选题，仅运行时授权题目 + 提示阶梯级数）、放行本机前端 3000 端口 CORS；
