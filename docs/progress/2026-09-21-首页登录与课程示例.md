# 2026-09-21 首页、独立登录与课程示例

## 本轮需求与实现

- 课表移至学生学习首页顶部，课程卡片置于其后；资源中心保留指向首页课表的链接，不重复放置课表组件。
- 保留原本地连接器、JSON 导入及浏览器存储格式。此次没有登录真实校园账号或修改连接器实现，也没有迁移用户数据。
- `/` 与 `/login` 使用独立登录注册页面，不显示工作台侧栏。有效会话按实际账号角色进入 `/student` 或 `/teacher`，教师/助教注册继续由后端校验邀请码。
- 未登录访问工作台、工具目录、安装页及旧入口统一转入 `/login`；本轮明确取代上一轮工具目录免登录的设计。localhost 的演示模式也需有效登录。
- 移除 Pilot 内嵌登录表单，退出登录、会话失效后返回独立登录页。API 权限仍由后端校验，前端跳转不替代后端鉴权。
- 五门课程各三条深入提问，AI 问答新增三条，共18条。使用简短标题与完整问题分离的配置，点击只填入草稿，须用户主动发送，不采用预制答案，也不宣称教材覆盖或模型能力因此提升。
- 数分涉及一致收敛、完备性及含参积分；高代涉及可对角化、二次型和最小二乘；物理涉及约束运动、电磁能流与熵；拓扑涉及紧致性、商拓扑与同胚；ODE涉及唯一性、稳定性与共振；AI涉及RAG证据链、评测泄漏和工具权限。
