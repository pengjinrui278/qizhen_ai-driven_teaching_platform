# AI素养支持模块

用户于2026-09-08明确的新方向，取代先前“AI教学模块方向未知、不改动”的临时约定。此处为开发方案，不表示已实现。

## 三部分

1. AI知识库与RAG问答：直接解释知识，包含教材、原书例题习题、试卷和个人笔记。不调用Student Mirror能力评估，不采用引导式教学，不生成作业Sandbox，不自动监测学习能力。
2. AI工具入口与逐步集成：对话、生图、视频、音乐、文案、办公、编程。根据官方接口和使用条款选择跳转、教程或接入；明确数据传输、费用和所需账号，不假装所有工具都能嵌入。
3. 经授权的本地安装助手：Claude Code、Codex、WorkBuddy、CC Switch等。网页不能自行取得本机安装权限；设计签名本地安装器或用户主动执行的可检查安装流程，环境检查、版本固定、官方来源校验、配置向导、失败恢复、卸载说明。不得在本次任务中未经授权替用户安装这些产品。

## 数据与权限边界

- AI素养问答与课程学习使用不同策略配置；不能仅靠系统提示词阻止能力评估，后端工具权限也须隔离。
- 个人笔记默认私有；自动整理须可预览、确认、编辑和删除。用户选择加入笔记的对话不能自动成为全校共享材料。
- 教材及试卷保留来源、版次和使用范围；上传用于RAG不等于授权公开全文或参数训练。
- 密钥由本地配置向导或服务端秘密管理保存，禁止出现在前端、URL、示例、日志、安装遥测中。
- 安装每一步说明作用和权限；管理员权限或外部账号授权应另行征得用户同意。

## 实施顺序

完成申报内容后继续数学分析教材复核与原题归并；建设课程资源页与可追溯关联图，再完善多角色执行、笔记与反馈。AI模块依次实现知识RAG、工具目录、本地部署助手。不得让AI模块阻塞已在推进的数学分析质量校验。
