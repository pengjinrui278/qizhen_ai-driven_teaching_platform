# 剪刀（引用片段 → 拼接 → 并行子页面追问）交接（2026-10-12）

## 用户要求

对 AI 回答中某片段有疑问时，复制粘贴重问会把原回答顶走、公式难复制、无法定点引用——阅读连贯性断裂。方案：
工具栏放「剪刀」，点击后鼠标变剪刀，在回答上框选若干片段（虚线框、可跨多答案多处连选），
选完「拼接」生成**与主页面并排的子页面**；片段以引用卡片呈现（显示不全的底部渐隐，悬停/点击展开），
在子页面里针对引用提问；子页面的回答可再剪，生成子页面 2（嵌在其右侧），以此类推；用户自行关闭。
整条回答也可被引用。用户已确认：先做课程对话页；粒度＝块级 + 段内可拖选文字（公式原子）；
追问正常落库但在历史里标记「追问」并归组；分段交付（M1 核心闭环，M2 多面板）。

## 实现（M1，分支 work/scissors，未推送）

- `chat-quote.mjs`：追问消息序列化/解析（首行 `【引用追问】` + `⟦引用 N · 来源⟧…⟦/引用 N⟧` + `⟦问题⟧`，
  内容里的 `⟦` 做不可见转义）；rehype 标注插件给块级元素打 `data-quote-start/end`（相对 normalizeMath 后的源串偏移）、
  给公式打 `data-quote-tex`。**两个实测坑**：① 在 rehype-katex **之前**打的属性会被 katex 重建元素时丢弃，插件必须排在它之后；
  ② katex 输出没有 position，行内公式有偏移、行间公式没有，TeX 一律从 `<annotation encoding="application/x-tex">` 反取；
  display 命中后不再下钻，避免内外两层都被选中。
- `ChatMarkdown.tsx`：与既有渲染管线一致、额外带引用标记的渲染器（不改既有 MessageText 行为）。
- `QuoteSurface.tsx`：选择层（点选整块、拖拽跨块连选顶层单元、段内拖选文字按 Range 还原文本与公式、Esc 退出、
  选中态按 key 回贴虚线框与序号）。**不覆盖 react-markdown 的 components**，只在 hast 上加属性，避免破坏既有样式。
- `QuoteTray.tsx`：引用卡片（底部署渐隐只在内容溢出时加，悬停/点击展开、移除、定位原文）+ 工具栏 + 浮动操作条 + 托盘。
- `QuotePanes.tsx`：pane 容器与子页面。子页面自建 attempt（`POST /attempts` 首条消息＝序列化引用+问题）→
  `messages/stream` 流式；每 pane 独立 AbortController、epoch 隔离；会话失效（404）显示「该子页面已失效」并可关闭。
- `quote-store.ts`：pane 树类型与 localStorage 持久化（键 `learning-mirror.scissors.v1.<userId>`，以主会话 attemptId 为命名空间，
  换会话即整套作废；events 不落盘，刷新按 attemptId 重拉）。`links` 记录「子会话→父会话」，供历史归组。
- CourseChat 集成（最小侵入，既有 epoch/lock/流式/历史逻辑未动）：`chatHeader` 加剪刀工具栏；中列包进 `.chatPanes`；
  消息文章带 `data-quote-src`；回答工具条加「引用此回答」；输入框上方引用托盘；新对话/切换历史关闭子页面（有内容先确认）。
- 历史归组：追问会话的服务端标题自带 `【引用追问】`（自描述、跨设备可识别），前端按 `links` 归组到父会话下并显示「追问」徽标，
  父行给出展开/收起与条数；`ChatHistoryList` 的 `followUpOf` 为可选属性，不传时行为与原先完全一致。
- 后端零改动；追问与普通问答同样落库、同样计入弱学习证据（符合既有管线约定，未新增"不留痕"机制）。

## 前端负责人注意

- 不要把 `annotateQuoteBlocks` 移到 rehype-katex 之前，也不要用 `components` 覆盖包裹块级元素（都会破坏既有渲染/样式）。

## M2（同日追加）：抽页收纳、拖拽换位与分隔条缩放

- **自动收纳**：`ResizeObserver` 观察面板条，放不下时**只收不放、从右往左**把面板收成抽页（`state:"tab"`），
  固定过的面板（`pinned`）跳过；收起父面板会**连带子树**。空间变大不自动展开，避免抖动。
- **抽页形态**：收成 46px 窄条，只显示页面标号 + 删除叉；悬停/聚焦抽出一半（52%）预览；
  标号条在展开后**仍然保留**（否则点击目标会在悬停瞬间消失，用户永远点不到）；点击标号 → 抽出并固定。
- **拖拽换位**：页头抓手按住拖动，整棵子树一起移动，落点用目标面板左右半区的实线指示；
  键盘等价通道 `Alt+←/→` 与**同父级相邻兄弟**交换（供无鼠标与自动化验收使用）。
- **分隔条缩放**：拖动按权重守恒分配相邻两页宽度，双击恢复均分；权重用**相邻两页的实际像素宽度**标定，
  能自然容纳抽页标签、间距与分隔条；主面板权重（`mainWeight`）随工作区持久化。
- **持久化**：权重、顺序、收纳态、固定态全部随 pane 树存 localStorage，刷新恢复（验收脚本已断言）。

### M2 期间修掉的四个真实缺陷

1. 抽页规则特异性低于面板基础规则，抽页面板宽度仍是 340px（收不下去）；
2. 悬停展开时把标号条一起隐藏，导致"鼠标一悬停、点击目标就消失"，永远点不中；
3. 主面板权重没接到 DOM（`children` 是数组，`cloneElement` 分支没生效）；
4. 分隔条左侧面板 id 用了循环里的 `let`（闭包读到终值），拖拽分配给了错误的面板；以及 `minW` 换算
   未计入抽页标签与间距，权重会越过 CSS 最小宽度，出现"一边变宽一边不动"。

## 用户试用反馈修复轮（2026-10-12 晚）

用户试用后提出五条，前四条已改完（第五条视觉部分见下）：

1. **编号不连贯** → 子页面标题改为**按位置派生**：主页面之后第 1 个永远是「子页面 1」，
   关闭再开不跳号；换位/收纳后编号随位置重排。`PaneState.title` 仅保留为历史字段。
2. **句段被当作原子对象** → 非公式部分改为**自由框选到字**：任意拖选（含跨块）都按 Range 精确取文，
   公式仍为原子（`\(…\)`）。**修掉一个一直存在的缺陷**：`range.cloneContents()` 返回的是
   DocumentFragment，旧实现只认元素/文本节点，导致整段拖选取到空串、静默退化为"整块选中"——
   也就是说自由框选此前从未真正生效过。HUD 文案同步改为"点选整段；按住拖动可精确到字，公式始终整块"。
3. **已选计数串页** → 剪贴托盘改为**按面板隔离**：`trays["main"]` / `trays[paneId]` 各自独立，
   工具条与操作条只显示本面板的计数，拼接只使用本面板剪下的片段；关闭面板连带清理其托盘。
4. **抽页 confising、点击无反馈** → 抽页标签改为竖排「子页面 N」+ 展开箭头 + 删除叉、浅底高亮、
   `title` 提示与整条可点；点击抽出后自动滚动到可见位置，并加强抽出动效（`panePull`）。
5. **展示空间不足的页面都要自动折叠** → 已是现状并保持：无论父页面还是子页面，
   空间不够时从右往左收起，**主页面永不折叠**，用户固定过的页面跳过；空间变大不自动展开。

### 手动折叠与顺序（用户追加要求）

- 每个子页面页头新增**收起键**（→ 图标）：按用户意愿把该页收成页边，只收这一页（不经子树）；
  页边点击即抽出并固定。自动收纳（只收不放、右起、固定页跳过、主页面除外）**保留**。
- **折叠页边与展开页面统一按编号排列**：两者都在同一条带里按位置顺序渲染，
  验收脚本断言 `data-pane-index` 序列恒为 1..N（换位后随新位置重排）。
