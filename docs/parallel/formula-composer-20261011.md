# 公式输入面板集成交接（2026-10-11）

用户要求：相机旁的小图标；面板紧贴提示词输入框上方并同宽；独立编辑后完成插入原光标位置，呈现排版公式而非源码；外部点击/完成关闭；符号可滚动；兼容LaTeX。

## 实现
- CourseChat接入FormulaComposer，原textarea改为可访问的contenteditable混合输入，KaTeX公式作为不可直接破坏的可编辑节点；点击节点重新打开MathLive编辑。
- 面板分式、上下标、根号、分段/矩阵、极限/积分/求和、关系/集合/希腊字母及数字字母；上一格、下一格、退格、清空、可选LaTeX源码。未填占位格不提交。
- 完成前不改主输入；完成恢复选区插入或替换公式，发送序列化为现有数学文本协议。后端接口/数据库未改；不向模型发送编辑器HTML。
- 点击外部暂存面板公式，不自动发送；切换会话/新建会话清空编辑器状态。发送中禁用编辑。中文输入法Enter不发送；Shift+Enter换行；粘贴仅纯文本，公式复制为数学文本。
- 桌面相机/公式/输入/发送横排；手机输入占整行，下行相机和公式相邻，面板仍与输入同宽。模板区滚动、完成按钮留在底部。
- MathLive 0.111.1（MIT）固定版本，fonts.css交由Next本地打包，动态客户端加载编辑器；构建不依赖外部CDN。锁文件仅新增该包，不改变现有依赖版本。
