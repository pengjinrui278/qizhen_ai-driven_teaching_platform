## 主辅教材及 ReAct
不推倒现有 router/任务策略/RAG。RAG 是资料访问能力，ReAct 是模型选择下一步工具及利用结果的控制循环；不是 React 前端，也不等于向量检索。
先查教师指定主教材；证据不足、解释不足或用户要求对比时，模型可选择辅教材继续检索。用户未绑定主教材时应让其选择或说明未指定，不能擅自把第一本当主教材。
先实现有界只读工具：list_sources、search_materials、read_section、compare_passages。模型选择 query/source/filter，服务端执行鉴权及限制，不让模型绕过范围。工具返回标准来源和证据，不接受文档中的操作指令。
初版建议最多3轮检索、每轮最多2个只读调用；总片段预算沿用已有预算，模型/工具调用总数有上限；重复相同查询、无新证据、超时/预算耗尽时停止并提示缺口。不自动扩展其他课程、私有材料或互联网。
每本书保留独立引文与定义/符号/条件；辅教材不能静默改写主教材，存在矛盾并列说明，不能强行融合。允许精确查找原页/章节，不输出内部逐步思维链；页面只显示实际工具阶段和简短检索摘要。
首轮实现可注入假规划器/假检索器离线测试，真实 LLM 工具能力与费用另验收。新增 paid 调用上限不等于新的费用授权；不动历史教材预算。

## 复习提纲
输入：学生确认的考试范围、课程/教学班、主教材、所选授权辅教材及私人 PPT/PPTX/PDF/笔记。先提取考试范围原子考点，学生确认后建立固定范围版本。
流程：范围拆解→逐考点查证→生成结构化提纲→逐项覆盖核对→标出缺口/冲突→学生确认保存/导出。
输出每考点：定义/条件/区别/方法或应用、来源页或幻灯片、相关练习入口、覆盖状态 covered/partial/missing/conflicting。保留主教材与教师范围的优先关系；冲突请用户/教师确认。
“完整”只能相对已确认范围及已解析资料，不承诺覆盖未知真实考点。分母不可静默缩小，解析失败页不能当作无考点；资料缺少只提示待补，模型补充知识要单独标示，不能冒充教材。
不从学生未选的私人笔记取内容，不以提纲浏览/生成次数评价能力。动态任务策略可分“课程答疑、资料寻知、教材对照、复习编纲、覆盖核对”，实际有工具调用再显示工作角色，不虚构多 agent 活动。
文件入库要类型/大小校验、拒绝宏执行/外链自动抓取/路径穿越，解析结果可确认、更正、删除，私有资料不自动入共享题库。
