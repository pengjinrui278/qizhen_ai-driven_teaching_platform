## 主负责人裁决：参考中的差异
1. 源稿约409行 @media(max-width:900px) 提前闭合，sidebar 60px等移动规则落在全局，出现多余闭括号。桌面截图也因此变成窄侧栏，不能像素复刻这个缺陷。以交接文档的桌面240px意图为准，移动窄栏60px；390px单列。副本仍保持原状，产品实现自行修正作用域。
2. 文档同时建议抽屉/底部栏和窄栏，首版依据用户选定稿及首页checklist采用窄图标栏；不另造抽屉/底部导航。每项点击区至少44px、有aria-label/当前页、键盘焦点；标签不可因hidden导致屏幕阅读器失去名称。
3. /student 是首页；/student/learn 是课程聊天，不改成首页；学习反馈真实路径 /student/observations，不凭稿中新建 /student/feedback 或 /student/profile。
4. 学生侧栏保留 /student、/student/learn、/student/ai、/student/resources、/student/assignments、/student/observations、/student/privacy；参考稿漏掉AI入口，不能据此删除。未实现复习提纲不放“新”的可点击入口；学生不显示TA审校。
5. 角色切换仅按已有后端身份/权限判断，不能点击提升权限。不为视觉新增权限系统，普通学生不显示教师工作台切换；若现有角色字段不能判定则报告，不编造可切换身份。真实教师页授权检查保持。
6. 课程列表来自API，实际多少就显示多少，不能强行凑8个、去掉拓扑或伪造新课。桌面采用设计card最小宽度约240px的自适应网格、390px单列，不为凑2x4造成挤压。
7. 欢迎文案用实际用户/时间；课表/待办/最近记录来自实际接口。现有数据无法支持的“已掌握知识点”、掌握百分比/薄弱点数量不展示，不从提问数推导。没有教材状态就不武断写“已覆盖”或“教材待补充”。合成验收数据只在测试拦截层，不能硬编码生产组件。
8. 源文件依赖飞书外部字体CSS，并非完全自包含。首版不增加运行时第三方字体请求；提供系统字体回退，字体授权/本地化另议。不要为满足截图复制外部script。禁止shadcn/Tailwind/图标库等新依赖，本次只做现有React与CSS映射。
9. CSS优先复用选定稿的颜色/圆角/阴影/spacing；设计变量使用 --lm-* 或等效命名并限定学生外壳。不把 --text/--primary 等泛名全局覆盖现有组件。
10. 手机课表允许容器内横向滚动，必须能访问七天；页面本身不横向溢出、不用overflow:hidden掩盖内容裁切。禁固定高度裁切课程、待办与导航。
