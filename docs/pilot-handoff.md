## 启动

安装 Python 3.12+、Node 22、pnpm 10。根目录执行：

    python -m venv .venv
    ./.venv/Scripts/python -m pip install -e "apps/api[dev]"
    pnpm install --frozen-lockfile

根据 .env.example 配置根目录 .env；本地可设 SQLite，模型默认 stub。
工作人员邀请码由开发团队设置 MIRROR_STAFF_INVITE_CODE，不提供固定默认口令。
启动两个终端：

    ./scripts/run-local.ps1 -Service api -Python ./.venv/Scripts/python.exe
    ./scripts/run-local.ps1 -Service web

浏览 http://localhost:3010/mirror。若代理触发来源保护，在 .env 中设置
MIRROR_CORS_ORIGINS=http://localhost:3010,http://127.0.0.1:3010。
部署 HTTPS 时设置 MIRROR_SECURE_COOKIE=true，MIRROR_ENVIRONMENT=production；
此时新作业默认168小时，当前test环境默认3小时，始终由教师确认。

初始化只补缺失课程包，不覆盖建设台版本。升级旧数据库前停服务并做一致性备份；
本轮数据库改动仅新增表，不删除旧表/改旧列。恢复备份须连同代码版本恢复。
不要用 import-all-coursepacks 覆盖已经人工修订的课程内容。

## 验收边界

- 学生注册、持续对话、每题提示阶梯、历史恢复、显式困惑观察和纠正。
- 两次不同尝试出现同类观察后才建议关注；自报成功不等于独立测试通过。
- 教师仅访问所属Sandbox聚合与明确提交作品；AI预审待人工校准。
- 合成作品与真实作品分开统计。到期清理成员、作品、临时题干及审核内容副本，
  私人学习记录脱离班级关联，按学生自己的保留期管理。
- 贡献先明确同意，再判课程范围，再编辑知识关联、解法与提示，最终教师确认发布。
- 五种学科计算工具只验证各自受限的结构化问题，不代表任意证明或模型整体质量。
- 默认Stub是离线协议演示，不能解决任意私人题。真实模型须配置供应方确认的
  base URL、API key 和 ds-v4-pro；目前没有真实模型质量/图像识别通过的结论。
- AI教学模块内容和页面保留，不在本轮重构范围；旧数理匿名接口已退役。

## 尚未完成的产品深度

当前Student Mirror是可解释的三主题证据机制，并非完整的个人知识图谱、
跨主题迁移推理或经过验证的自适应教学策略。
课程建设支持逐题版本，不是整包原子发布；数据库升级目前是新增表，
尚非带自动降级的通用迁移系统。教师班级候选仍需人工审查。
缺少真实模型评测集的人工标注、对照实验及费用基准；
现有工具回归不能替代这些工作。教材扫描PDF/OCR的真实效果亦未验收。
这些应继续推进，不应因为本地验收通过而标记为全平台目标已经完成。
