学镜 Windows 安装助手 0.1.2

1. 解压整个压缩包到普通文件夹，不要直接在压缩包内运行。
2. 双击 Start.cmd。请选择你信任的学镜下载来源；本预览版尚无代码签名。
3. 在助手中核对工具，先“检查环境”。WinGet 包含在微软“应用安装程序”中，由助手自动调用，不需要自己输入安装命令。缺少时，通过“获取 WinGet”进入微软商店，完成“应用安装程序”的安装或更新，再重新打开助手；仅下载安装包不等于安装完成。
4. 阅读工具官方指引与许可，勾选确认，点击“安装所选工具”。
5. 状态显示的是安装记录核验，不等于账号登录、API 配置或实际模型功能测试已完成。

支持 Windows 10 2004+、Windows 11，要求 WinGet 1.12+。
会直接检测 Windows 标准命令入口，已安装但未加入 PATH 也可以使用，不修改系统环境变量。旧解压目录不会自动更新，请重新下载并解压到新文件夹，确认窗口标题含 0.1.2。
Codex、Claude Code、CC Switch 支持本次清单中的 x64/ARM64；WorkBuddy 仅核对 x64，不在 ARM64 上自动尝试仿真安装。
使用固定 WinGet 包名、核对版本、官方 winget 源；不关闭哈希验证，不下载转发站安装包，不关闭杀毒或 SmartScreen。
Start.cmd 仅为本次 PowerShell 进程设置执行策略，不更改电脑的持久执行策略。组织策略禁止执行时，请联系管理员，不要绕过。

已有工具默认跳过，不升级、不降级，不改写工具模型配置，不读取或收集 API 密钥。
若安装失败，停止后续任务；已安装工具不自动回滚或卸载。停止按钮不会强杀正在写文件的安装程序。
如超时，WinGet 或第三方安装进程可能仍在运行；先检查任务管理器，确认结束后再重试。
任务记录仅存在本机 %LOCALAPPDATA%\LearningMirror\Installer\runs。不上传到学镜。
失败时先读界面中的“失败环节、原因、当前状态、建议处理”，不要只看错误码。
“本次详细记录”：status.json 保存任务结果；command-xx 日志保存每次 WinGet 命令的输出和错误码；worker-error.log 用于助手进程异常。
“WinGet 日志”：打开微软的详细日志目录，按修改日期找到本次失败时间的文件。校验失败发生在运行安装包之前，权限或安装器失败则可能已有部分安装，不能混为一谈。
“复制故障摘要”：复制软件、开始时间、错误码与处理建议，不自动上传。分享前检查个人信息；不要发送密码、API 密钥或未经检查的完整日志。
若报安装包完整性校验失败，禁止关闭哈希验证或强制安装。由维护人员核对官方文件与微软清单，确认后再更换版本或重试。
工具已存在会跳过；环境检查通过不代表后续下载一定成功；安装记录通过也不代表已经登录、配置模型或完成实际使用验证。
第三方安装器及 WinGet 会连接各自服务器，受相应条款约束。
卸载工具：Windows 设置 → 应用 → 已安装的应用。卸载助手：删除解压目录即可；任务记录可由本人另行删除。

账号及 API：
- Codex：运行 codex 后使用官方支持的登录方式。
- Claude Code：运行 claude 后按官方指引认证。
- WorkBuddy：启动客户端完成官方登录。
- CC Switch：先在应用内备份原有配置，再添加服务商和自己的密钥。
- 不保证同一 DeepSeek 密钥或接口协议适用于全部工具，不向个人电脑分发平台服务器密钥。

首版安装自动化和隔离测试已实现；仍须在干净 Windows 机器完成真实安装验收。
