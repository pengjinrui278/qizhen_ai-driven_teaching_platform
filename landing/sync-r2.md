# 学镜 Learning Mirror｜豆包 UI 同步任务 R2
日期：2026-09-26；来自主负责人。此文可独立阅读，无需访问代码工作区。
请先分析下列信息架构，说明对现有稿的改动，再提供更新设计。保留用户认可的视觉语言，不另起一套风格。

## 定位与现状
学镜学习空间 / Learning Mirror：独立学生端、教师端；助教是教师工作流中的受限角色，不独立造第三个互不关联平台。
已存在：独立登录注册、学习首页及课表、课程聊天、作业、教材/试卷资源、学习反馈、隐私；AI素养的独立问答、资源、笔记、工具目录与Windows安装助手。
聊天有图片识别后文字确认、历史、公式、阶段进度与失败重试。当前是阶段状态+校验后完整回复，不是逐token；不要设计假多agent思考过程。
新功能是计划/开发中，不是已上线；稿中可演示状态，但要在设计说明中注明模拟，不能当作真实产品数据。

## 信息架构及页面职责
学生首页：我的课程、我的课表、待办作业；不要堆完整资源搜索和大段介绍。
课程学习：课程入口→聊天/教材与资源/例题习题/真题卷/我的笔记/复习提纲。可为独立路由或明确课程子页，保留返回课程和当前课程。
资源总入口：跨课程检索；课程内资源默认限定本课，复用同一资源体系，不是第二份目录。
学习反馈：经授权学习记录和可纠正建议；提纲的资料覆盖不是能力雷达值。
教师：课程与主辅教材设置、教学范围、作业提交/批改、共性反馈；只能看有权限的教学内容，不看私人聊天和笔记。
助教批改：候选错误、证据、确认/修改/否决；教师最终审批按任务权限出现，不能让普通助教拥有课程管理权限。
AI素养：直接知识问答+资源/笔记；工具分类包括对话/生图/视频/音乐/文案/办公/编程；安装助手帮助新手看错误、解决办法和日志。不是课程能力评估入口。

## 新增四课：不要只换名字
Python：代码块、报错位置、测试示例、分步调试，代码执行未批准时不要放虚假“运行成功”。
电子电路基础：电路图查看、符号/单位/假设定位。
心理学及应用：概念辨析、案例与研究来源，不能做心理诊断卡。
大学英语：语境、阅读证据、文本修改对照和理由；不是数学证明式对话。
教材尚未提供，设计有明确“教材待补充”状态，不能每课都填虚假教材和进度。

## 主辅教材与可理解的检索过程
展示教师指定主教材、选用辅教材、书名版次、章节/页码或幻灯片号。
回答优先主教材，辅书用独立来源卡辅助解释；跨书对比展示术语/条件差异，不强行统一。
工作状态可用“查找主教材”“对照辅助资料”“核对出处”，仅在系统确实执行时出现，不展示内部思维链。
缺主教材/缺证据/资料冲突/没有访问权限/解析未完成都有空态或反馈。

## 资源与真题
桌面：搜索栏+课程/资料类型/主辅/年份筛选+结果列表；可在列表与详情之间切换，避免大卡片占屏。
手机：搜索与筛选收拢，清晰题号/书页定位，拍照/上传入口可点击，别用悬浮框遮正文。
搜索结果区分标题与正文命中，显示分页/更多，不能设计一次装载全部。
试卷详情保留课程、学年、期中/期末、原卷页码、题号与子题；题干和答案解析分区。授权允许才有原卷查看/下载。
目前确认仓库有9份物理历年卷原件，尚不表示题目全部审校入库。

## 复习提纲重点页
流程：填写/上传考试范围→选择主辅教材及自己的PPT/PDF等→确认考点→生成→逐考点核对和编辑/导出。
呈现目录、重点概念/条件/方法、出处、相关练习。每考点状态：已有资料支持/部分支持/缺资料/存在冲突。
覆盖率明确是“已确认考试范围的资料覆盖”；不声称“期末必考全部覆盖”，不暗示学生已掌握。
支持范围修订后重新核对、定位缺失材料、上传失败重试、取消、空态和版本变化提示。
用户私人复习文件不能默认共享。文件类型以实际后端支持为准，未支持的格式给明确说明。

## TA Copilot 设计状态
已提交→待分析/分析中→候选待审→TA确认/修改/否决→必要时教师审批→完成。
错误/超时待处理、版本变更需重审、到期不可操作都要有状态；AI候选不直接显示成最终扣分结论。
并排学生原图/确认文字与候选依据；确认操作应明确，批量批准不可误触。人工已修改后迟到结果不能跳回旧状态。

## 视觉约束
蓝色主调，低饱和、轻渐变、清晰层级；成熟教学平台感，少说明，不加装饰英文。品牌英文 Learning Mirror。
不展示开发清单、sandbox、router、skill、ReAct 等工程术语。中文正文清晰可读，不能靠大量小字解释功能。
用户曾要求删除无用小字；实际工作角色如需展示可用简短次级状态，但保持可读，不增加“多智能体”宣传段落。
桌面和390px手机都设计；键盘焦点、错误对比、图表文字标签齐全，不能只靠红绿颜色。
学习反馈图表只用明确标记的演示数据，勿虚构真实能力或成绩提升。
