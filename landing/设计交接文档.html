四、分类清单

4.1 仅改样式（不动结构）

  • 我的作业页：套用 gcard 样式、徽章配色、状态 tab
  • 学习档案页：薄弱点卡片左边框色、柱状图渐变色、进度条配色
  • 隐私页：图标色、toggle 配色、按钮样式
  • 全站按钮、输入框、徽章、卡片 hover 态

4.2 需重排布局或拆组件

  • 首页：欢迎区+统计条、课表 7 列周视图、课程 grid 从 4 卡改 8 卡（auto-fill minmax(240px,1fr)）
  • 课程对话：新增子导航 tab 行；右侧关联教材面板从简单列表改为"工作状态指示条 + 段落卡片"结构；消息气泡和 hint-pill 工具条重排
  • 资源中心：筛选从单行按钮改为四组 filter-bar（课程/类型/主辅/学年）；结果区保留教材封面 grid + 真题卷列表行双区
  • 侧边栏：从 6 项扩为 8 项，新增"复习提纲""TA 审校"，带红色"新"角标在 icon 左上角

4.3 涉及功能/导航/权限变化，需产品确认

  • 复习提纲页：完整新功能流程（填范围→选教材→确认考点→生成→核对→导出），需后端接口支持
  • TA 审校页：学生端导航不显示，仅教师/助教角色可见；审批流（TA 确认→教师审批）需权限系统配合
  • 课程子导航：6 个子页路由需确认（对话/教材资源/例题/真题/笔记/提纲），目前设计稿只做了"对话"子页的视觉
  • 主辅教材：关联教材面板需区分主教材/辅教材来源卡，工作状态文案需后端真实状态驱动
  • 新增四门课：Python/电子电路/心理学/大学英语的课程数据和教材接入，后端未就绪前前端显示"教材待补充"空态
  • 侧边栏"切换到教师端"：跳转目标和角色切换机制需产品确认

4.4 设计缺失项（前端接入时需补，不要猜）

  • 加载态：设计稿未画骨架屏/loading spinner。统一用主色 20% 透明度的脉动占位块
  • 错误态：API 失败未画。用 rose 色左边框卡片 + 重试按钮，参考"缺资料"卡片的 rose 配色
  • 空态：仅在复习提纲"缺资料"和资源中心有部分体现；聊天无消息、作业为空、搜索无结果需补空态（参考 .empty-state 类）
  • 手机端步骤条：复习提纲五步条在 390px 下"导出"被截断，需改为横向可滚动或紧凑步骤（图标+数字，隐藏标签）
  • 手机端侧边栏：当前折叠为 56px 图标列，无汉堡菜单逻辑；手机端应改为底部 tab bar 或抽屉菜单，需产品确认交互
  • 代码块（Python）：CSS 已备 .code-block（深色 #0f172a 底），但设计稿未展示 Python 对话页实际效果，接入时按 .code-block 样式套用
  • 登录页：未在设计稿范围内，沿用现有登录页

六、首屏验收建议（先做这页）

第一步只做：学习首页 + 公共侧边栏导航。 不要全站一起改。前端先在项目里建立 CSS 变量（第二节的 token），然后只把首页和侧边栏映射到 shadcn/ui 组件，桌面 1440 和手机 390 各出一版截图给我验收。 确认颜色、字号、间距、icon 粗细无误后，再推广到课程对话、资源中心等其他页。

首页验收 checklist

  • 页面背景 #eef2f7，无大块纯白
  • 侧边栏白底 240px，导航 active 项是淡紫底 #4f46e5 深紫文字
  • 课程卡片白底圆角 14px，hover 上浮 3px + 阴影加深
  • 课程封面渐变色（数学分析紫→青、高代蓝、物理粉、常微分绿、Python 橙、电路琥珀、心理粉紫、英语蓝）
  • "教材待补充"标签是琥珀色底琥珀色文字
  • 手机 390px：课程卡片单列堆叠，侧边栏折叠为窄图标列

验收时不要做的事

  • 不要把设计稿里的假数据（"张同学""数分习题三"）当真数据搬入
  • 不要把静态按钮做成无交互僵尸按钮，每个入口要接真实路由或 toast
  • 不要改变登录跳转、聊天提交、图片上传、公式渲染等已有功能
  • 不要自行加装饰英文、暗色模式、emoji、"多智能体"宣传文案

7.3 历史会话交互

  • 新对话：不是清空历史，是新建一条会话，历史列表保留
  • 选中态：淡紫底 #4f46e5 深紫文字，左侧对话图标变紫
  • 删除：hover 时右侧出现垃圾桶图标，点击删除该条
  • 长标题：white-space:nowrap;overflow:hidden;text-overflow:ellipsis
  • 空态：无历史时显示居中图标+"还没有对话，开始第一道题吧"
  • 加载态：列表顶部显示脉动点+"加载历史会话…"
  • 失败重试：rose色提示+"加载失败"+重试按钮
  • 手机抽屉：.drawer-overlay 半透明遮罩，点击遮罩或历史项后关闭

7.4 回复后操作组（替代常驻顶部按钮）

  • 触发时机：最新一轮 AI 回答成功完成后 3 秒，在该回复气泡底部显示
  • 三个按钮：我卡住了 / 再深入一点 / 梳理解题框架
  • 仅最新一轮：历史轮的回复不显示操作组，避免堆满可点按钮
  • 状态限制：请求中 / 失败 / 取消时不显示，不得伪装完成
  • 动画：opacity:0→1, translateY(4px)→0，0.3s ease
  • 禁用态：用户点击后按钮 disabled，opacity .4
  • 无倒计时装饰：3秒由前端 setTimeout 实现，不画进度条或倒计时数字

八、R5 侧栏与反馈样式（2026-10-05）

核心原则：学习反馈不做第二个聊天历史列表；活动不等于能力证据；普通提问不显示为掌握或进步；不虚构分数、进度百分比、学习成果。 对应前端：LearningFeedback（learning 负责人）、CourseChat 左栏（web 负责人）。

8.1 学习反馈页三块结构

区块内容禁止
课程阶段概览（顶部）每门课当前真实章节（蓝色文字）、最近活动时间；无活动课程不出现不显示进度%、雷达图、能力分数
活动时间线（主体）蓝色竖线+圆点；每条含活动类型标签（提问/查看教材/练习/等待中/未完成）、课程、时间、语义概括、来源跳转/主题分类普通提问只标"提问"不标掌握；不用红绿判断能力；AI素养不进入
待复习事项（底部）仅有真实证据的复习点：名称+简短证据（如"2次请求提示后完成"）+练习入口；学生自报标弱证据不标红色"薄弱"；无证据不显示；不编造教材出处
