理解定义、定理与证明思路。从一道题开始，我会一步步引导你思考。

我
证明：若 lim xn = a，则 lim |xn| = |a|，反之成立吗？
Course Mirror · 数学分析
好问题。先回忆一个关键不等式——你能想到哪个不等式联系了 ||x| − |a|| 和 |x − a|？
  1. 想想绝对值的三角不等式
  2. 它的反向形式是什么？
试着写一下，我再帮你往下推。
我
是 ||x| − |a|| ≤ |x − a| 吗？
Course Mirror · 数学分析
没错，就是它。这就是三角不等式的反向形式。现在用极限的 ε-N 定义来完成证明：
  1. 任给 ε > 0，由 lim xn = a，存在 N，当 n > N 时 |xn − a| < ε
  2. 代入反向不等式：||xn| − |a|| ≤ |xn − a| < ε
所以 lim |xn| = |a|。

反过来成立吗？考虑在 a 和 −a 之间振荡的数列，比如 xn = (−1)n，你发现了什么？

题目：证明 limn→∞ xn = a，则 lim |xn| = |a|

学生：由极限定义，对任意 ε > 0，存在 N，当 n > N 时 |xn - a| < ε。

所以 ||xn| - |a|| = |xn - a| < ε。AI 标注：此处误用绝对值等式

AI 候选依据

疑似错误：绝对值不等式方向

学生写 ||xn| - |a|| = |xn - a|，但由反向三角不等式应为：

||xn| - |a|| ≤ |xn - a|

结论方向正确，但推导中写成了等号，应改为 ≤。

出处：主教材 §1.3 定理 1.2（三角不等式及其反向形式）· 第 11 页
